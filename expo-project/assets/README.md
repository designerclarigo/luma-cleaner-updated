# Bundled visual assets

Existing Luma launcher/adaptive/splash/favicons and canonical SVG branding are retained.

The approved preview uses Plus Jakarta Sans and JetBrains Mono. Offline TTFs are copied from official `@expo-google-fonts/plus-jakarta-sans@0.4.2` and `@expo-google-fonts/jetbrains-mono@0.4.1` packages. Font licenses are next to the files in `fonts/`.

The three offline onboarding photos match the approved preview’s imagery. Source: Unsplash images `photo-1506744038136-46273834b3fb` (Yosemite), `photo-1470071459604-3b5ec3a7fe05` (Pine Fog), and `photo-1507525428034-b723cf961d3e` (Pacific Cove), downloaded with auto format, crop, width 600 and quality 85. Their original provider URLs remain in the demo catalog. These are illustrative welcome photos, never substitute device gallery assets.
